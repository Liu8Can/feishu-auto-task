# 飞书动态下班打卡助手 Demo

这是一个面向 Windows 11 和飞书 7.76 的第一版演示程序。核心目标是读取当天上班打卡时间，计算最早下班时间，到点后二次确认页面状态，并且最多自动点击一次“下班打卡”。

## 当前范围

- 使用 `UI Automation` 读取飞书控件，不使用固定坐标。
- 可以通过系统协议打开飞书工作台；首次使用建议手动打开“考勤打卡”页面。
- 默认是演练模式，只判断是否满足条件，不执行点击。
- 自动模式会在点击前再次读取页面，两次结果完全一致才继续。
- 点击前先写入当天尝试记录；结果不明确时当天不再自动重试。
- 当前不处理锁屏、睡眠唤醒、节假日接口和 OCR。

## 运行

首次安装依赖：

```bat
setup.bat
```

启动演示程序：

```bat
run_demo.bat
```

建议先在飞书打开“工作台 - 考勤打卡”，启动程序后点击“诊断当前页面”，确认页面和唯一按钮都能识别，再使用“立即检查”。演练通过后才能考虑切换到自动模式。

## 配置

配置位于 `config/config.json`。默认规则是工作 480 分钟，加 5 分钟安全缓冲，15:00 至 23:30 检查，周一至周五运行。

## 测试

```bat
set PYTHONPATH=src
.venv\Scripts\python.exe -m pytest -q
```

自动化测试只使用假页面，不会连接或点击真实飞书。
