程序读取当天上班打卡时间，扣除休息时段后计算最早下班时间，到点后再次核对飞书假勤页面，并完成一次下班打卡。

> 当前稳定版 `v1.0.0` 已实现自动下班打卡。自动上班打卡已列入 `v1.1.0` 开发计划，将沿用同等级的页面确认、防重复点击和结果核验机制。

## 主要功能

- 自动启动飞书，并从导航栏打开“假勤”。
- 自动读取今日上班时间和预计最早下班时间。
- 支持“实际上班时间 + 有效工时”和“固定上下班时间”两种算法。
- 支持自定义有效工时、休息时段、安全缓冲、重试次数和重试间隔。
- 登录 Windows 后自动在后台运行，关闭或最小化主窗口后进入系统托盘。
- 点击前失败可有限重试；一旦已经调用点击但结果不明确，当天不会自动重复点击。
- 提供页面诊断、重新绑定、运行记录和安全手动重置。

## 使用条件

- Windows 10/11，64 位系统。
- 已安装并登录飞书桌面端。
- 将“假勤”固定在飞书左侧导航栏。
- 到达打卡时间时，电脑需要保持开机、唤醒且 Windows 已解锁。
- 当前版本针对中文飞书桌面端测试，飞书升级后可能需要重新绑定页面。

程序不能绕过 Windows 锁屏，也不能从关机状态自行开机。锁屏或睡眠期间不会尝试点击，恢复到可交互桌面后再继续检查。

## 首次使用前必须完成

> **必须先把“假勤”固定到飞书左侧导航栏。** 这不是可选设置。助手依靠左侧导航栏中唯一的“假勤”入口自动打开考勤页面；如果没有固定，飞书虽然可以被启动，但助手可能无法进入假勤页面，后续绑定和后台自动打卡都会失败。

首次使用请先完成下面四步：

1. 打开并登录飞书桌面端。
2. 找到“假勤”，将其添加或固定到飞书左侧导航栏。不同飞书版本中的入口文字可能显示为“固定”“添加到导航”或“添加到常用”。
3. 从左侧导航栏点击“假勤”，确认能够直接打开今天的考勤页面。
4. 再打开助手，进入“连接”页面完成“重新绑定页面”和“运行诊断”。

完成后的判断标准是：飞书左侧始终可见“假勤”入口，助手的连接诊断同时显示“今天假勤页已确认”和“页面绑定有效”。

## 首次试用教程

### 1. 准备飞书

打开飞书并确认已经登录。检查左侧导航栏中是否始终可见“假勤”；如果没有，请先按上面的“首次使用前必须完成”进行固定。然后从该入口进入今天的假勤页面。

### 2. 绑定页面

打开助手的“连接”页面，按顺序操作：

1. 点击“打开飞书假勤”。
2. 确认飞书显示的是今天的假勤页面。
3. 点击“重新绑定页面”。
4. 等待连接页显示“页面绑定成功”。
5. 点击“运行诊断”，确认飞书窗口、今日假勤页和页面绑定均为有效状态。

绑定过程只读取页面，不会点击打卡。正常情况下只需绑定一次；飞书升级导致页面结构变化时再重新绑定。

### 3. 设置时间规则

进入“规则”页面。默认规则是：

- 按实际上班打卡时间动态计算。
- 有效工作时长 480 分钟。
- 休息时间 12:00 至 14:00，这两个小时不计入工时。
- 安全缓冲 5 分钟。
- 点击前失败最多尝试 3 次，每次间隔 5 分钟。

例如，上班时间为 08:31，按上述规则计算，最早下班时间是 18:36。

也可以切换为固定上下班时间。固定模式下，如果实际上班晚于设置的固定上班时间，下班时间会相应顺延。

### 4. 验证读取结果

回到“今天”页面。程序启动后或绑定成功后，会立即读取并显示：

- 今日上班时间。
- 预计最早下班时间。
- 下一次检查时间。

在预计下班时间之前点击“立即检查”只会读取和计算，不会提前打卡。到达允许时间后，自动模式会执行严格复核并尝试一次下班打卡。

### 5. 保持后台运行

最小化或关闭主窗口后，程序会进入右下角系统托盘，不会退出。双击托盘图标可重新打开，右键菜单可以暂停监控或退出。

“登录 Windows 后自动在后台运行”默认开启，可以在“规则”页面关闭。

## 自动打卡的安全机制

真正点击前必须同时满足以下条件：

- 当前日期属于已配置工作日。
- 当前时间位于检查时段内，且不早于计算出的最早下班时间。
- Windows 当前是可交互的已解锁桌面。
- 页面日期为今天，绑定信息与当前假勤页面一致。
- 页面中存在唯一、可见且可用的“下班打卡”按钮。
- 点击前连续两次页面快照一致。
- 当天没有已经开始过的打卡点击。

点击前失败可以有限重试。只要点击调用已经开始，即使结果无法确认，也不会自动重复点击，避免重复操作。

## 版本计划

- `v1.0.0`：自动读取上班时间、计算最早下班时间并完成下班打卡。
- `v1.1.0`：增加可配置的自动上班打卡时段、独立防重状态、有限重试和结果核验。

上班自动打卡仍受 Windows 桌面状态限制：电脑关机、睡眠、锁屏或尚未登录时，程序无法操作飞书。相关功能在 `feat/auto-checkin` 分支开发，完成验证后再合并到稳定版。

## 常见问题

### 页面绑定一直没有结果

当前版本会持续显示“正在绑定”、成功、失败或 30 秒超时提示。如果发生超时，请退出助手后重新打开，并确认飞书停留在今天的假勤页面。

### 今日上班时间显示为空

先进入飞书今天的假勤页面，确认页面已经显示上班记录，再在助手“连接”页运行诊断或重新绑定。启动和绑定成功后，助手会自动读取今日时间。

### 最小化后找不到窗口

程序会隐藏到系统托盘。点击任务栏右侧的上箭头，找到助手图标并双击。图标是否直接显示在任务栏由 Windows 管理。

### 锁屏后还能自动打卡吗

不能。Windows 锁屏时禁止桌面自动化。请确保到达打卡时间时电脑处于唤醒且解锁状态。

### 飞书已经显示打卡成功，但助手显示结果不明确

程序不会自动重复点击。重新打开飞书假勤页面并点击“立即检查”，程序会继续只读核验当天记录。

## 数据与隐私

程序通过 Windows UI Automation 在本机读取和操作飞书桌面端，不接入飞书开放平台，不上传考勤信息。配置、状态和日志保存在：

```text
%LOCALAPPDATA%\FeishuClockoutAssistant
```

日志不记录密码，但公开反馈问题前仍建议检查其中是否包含不希望公开的工作时间信息。
