# 飞书动态下班打卡助手 Demo

这是一个面向 Windows 11 和飞书 7.76 的第一版演示程序。核心目标是读取当天上班打卡时间，扣除休息时间后计算最早下班时间，到点后二次确认页面状态，并且最多自动点击一次“下班打卡”。

## 当前范围

- 使用 `UI Automation` 读取飞书控件，不使用固定坐标。
- 检查时可以自动启动飞书、打开工作台并进入唯一的“假勤/考勤”页面。
- 第一次使用需要在当天考勤页执行一次“绑定考勤页”，后续只接受相同容器结构。
- 时间设置支持两种方式：按实际上班时间和有效工时动态计算，或者使用固定上下班时间。固定模式下若实际上班晚于计划时间，下班时间会相应顺延。
- 动态模式默认有效工时 480 分钟、休息时间 12:00 至 14:00、安全缓冲 5 分钟。休息时段与工作过程重叠的部分不计入工时。
- 默认是演练模式，只判断是否满足条件，不执行点击。
- 自动模式会在点击前再次读取页面，两次结果完全一致才继续。
- 自动模式要求页面能确认当天日期、考勤容器和唯一按钮身份，并在最终点击前再次检查桌面未锁定。
- 点击前先写入当天尝试记录；结果不明确时当天不再自动重试。
- 当前不处理睡眠唤醒、节假日接口和 OCR；锁屏时会安全停止。

## 运行

首次安装依赖：

```bat
setup.bat
```

启动演示程序：

```bat
run_demo.bat
```

启动后可以直接点击“打开飞书考勤页”。首次使用依次执行“绑定考勤页”“诊断当前页面”和“立即检查”；演练通过后才能切换到自动模式。工作时长、休息时间、固定上下班时间和自动打开选项均可在“时间设置”中修改。

## 配置

配置位于 `config/config.json`。默认规则是动态计算 480 分钟有效工时，扣除 12:00 至 14:00 的休息时间，再加 5 分钟安全缓冲；15:00 至 23:30 检查，周一至周五运行。

## 测试

```bat
set PYTHONPATH=src
.venv\Scripts\python.exe -m pytest -q
```

自动化测试只使用假页面，不会连接或点击真实飞书。
