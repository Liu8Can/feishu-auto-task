## 飞书动态下班打卡助手 v1.0.0

首个公开试用版。

### 功能

- 自动读取今日上班时间，并计算最早下班时间。
- 支持动态工时与固定上下班两种计算方式。
- 自动启动飞书并打开导航栏中的“假勤”。
- 到点后严格复核页面并执行一次下班打卡。
- 支持系统托盘、登录自启动、有限重试和跨日重新布防。
- 提供连接诊断、页面重新绑定、运行记录和安全手动重置。

### 默认规则

- 有效工时：8 小时。
- 休息时间：12:00–14:00。
- 安全缓冲：5 分钟。
- 点击前失败：最多 3 次，每次间隔 5 分钟。

### 使用前必读

- 仅支持 Windows 10/11 64 位系统和中文飞书桌面端。
- 请先将“假勤”固定在飞书左侧导航栏，并按 README 完成首次绑定。
- 到达打卡时间时，电脑必须保持开机、唤醒且 Windows 已解锁。
- 本项目未经代码签名，Windows 可能显示来源提示。
- 请以飞书中的最终考勤记录为准。
