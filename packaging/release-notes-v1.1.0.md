## 飞书自动打卡助手 v1.1.0

本版新增可选的上班自动打卡，并将上下班任务升级为独立调度、独立状态和独立防重。为避免升级后意外点击，上班自动打卡默认关闭，需要用户核对时间范围后手动启用。

### 新增与改进

- 新增上班自动打卡，可分别设置上下班检查时间范围和启用状态。
- 上下班任务独立记录尝试次数、结果和重试状态，互不影响。
- 新增一次性点击令牌，点击前再次核对日期、动作、页面和按钮身份。
- 点击一旦开始，结果不明确时不会自动重复点击，只继续核验飞书记录。
- 旧版配置和下班状态会自动迁移；升级后仍默认只启用下班自动打卡。
- 新增跟随系统、浅色、深色三种界面主题。
- 系统从睡眠或长时间停顿恢复后，会重新安排仍在有效时间范围内的检查。

### 使用前必读

- 上班自动打卡默认关闭。请先确认飞书“假勤”页面能够正常识别，再设置时间范围并手动启用。
- 请先将“假勤”固定到飞书左侧导航栏，并按 README 完成首次绑定。
- 到达检查时间时，电脑仍需开机、唤醒、已登录且桌面已解锁。
- 278 项自动化测试均使用模拟页面，不连接或点击真实飞书；上班自动打卡尚未经过真实上班场景验证。
- 当前按固定星期判断工作日，未自动接入法定节假日和调休安排。
- 飞书页面结构或文案变化可能导致识别失败，请以飞书中的最终考勤记录为准。

### 升级说明

`v1.0.0` 配置会自动迁移并保留原下班时间范围。`v1.1.0` 会写入新版配置和状态格式，降级前请先备份 `%LOCALAPPDATA%\FeishuClockoutAssistant`。
